## 🔧 Customization Guide

### Color Themes
Modify CSS variables in `:root` to create custom themes:
```css
:root {
  --primary: #your-color;
  --secondary: #your-color;
}
```

### Animation Speed
Adjust animation durations:
```css
.holographic {
  animation-duration: 2s; /* Default: 3s */
}
```

### Effect Intensity
Control effect opacity and blur:
```css
.cyber-border::before {
  opacity: 0.8; /* Default: varies */
}
```
